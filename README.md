# 🛒 E-Commerce Project

A full-stack e-commerce web application where users can browse products, place orders, and manage accounts.

---

## 🚀 Features

- User registration and login
- Product browsing
- Add to cart
- Order placement
- Admin dashboard (manage products/users)
- Supplier & bank modules
